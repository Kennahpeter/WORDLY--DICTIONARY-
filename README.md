# Wordly Dictionary

A single page dictionary app I built for searching words . You type
an English word and it shows the meaning on the same page.

It uses plain HTML, CSS and JavaScript, and the
[Free Dictionary API](https://dictionaryapi.dev/)


what it does

- Search a word with a form
- Shows the phonetic spelling, part of speech, definitions, examples,
  synonyms and the source link
- Save words you like, click them later to look them up again
- The saved word that is on screen is highlighted
- Light and dark theme button
- Error messages for empty input, invalid input, word not found, server
  problems and no internet
- Saved words and theme are remembered with local storage 

The Dictionary is live at (https://kennahpeter.github.io/WORDLY--DICTIONARY-/)
